# Spotify Clone

Modern Spotify Clone built using HTML, CSS and Vanilla JavaScript.

## Features

- Artist Playlists
- Music Player
- Queue
- Favorites
- Recently Played
- Search
- Shuffle
- Repeat
- Toast Notifications
- Keyboard Shortcuts
- Responsive Design

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)
